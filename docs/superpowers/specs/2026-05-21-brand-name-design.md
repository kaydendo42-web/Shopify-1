# Brand Design — The Quiet Hour™

**Date:** 2026-05-21
**Status:** Locked
**Replaces:** "Lumen Ritual" placeholder used throughout theme + foundational docs

---

## 1. Decision summary

The brand is **The Quiet Hour** (with trademark symbol on first use per page).
Working domain targets: `thequiethour.com`, `thequiethour.com.au`.
Working social: `@thequiethour` across IG, TikTok, Pinterest.

## 2. Scope (defines name DNA)

Locked: **beauty-tech for the phase**. The brand sells red-light therapy devices and accompanying topicals for women navigating perimenopause (38–55), with the option to extend into adjacent body devices over time. It explicitly does NOT extend to supplements, HRT, or anything that crosses the TGA / FDA medical-claim line.

## 3. Tone

Locked: **warm-spa**. Reference points are Aesop, Sodashi, Frank Body's premium-soft line, Le Labo, and the editorial voice of Adore Beauty's product reviews. The brand writes in lowercase by default, with short sentences, soft periods, and frequent em-dashes — like that. It is unmistakably adult, unmistakably feminine, and unmistakably not gen-z.

## 4. Brand thesis (one sentence)

> The Quiet Hour is the ten-minute window where she's not needed by anyone. The mask is what makes the window possible.

Every page, ad, email, and product description returns to this thesis. The visible change in her skin is the proof the time was earned.

## 5. Why this name (against the locked criteria)

| Criterion | How "The Quiet Hour" hits it |
|---|---|
| **Sector-stretch** | A thesis, not a noun. Every future SKU becomes "your Quiet Hour for X." |
| **Warm-spa tone** | The words themselves are the brand: hush, slowness, candle, robe, page-turn. |
| **Perimenopause-coded without saying it** | The tension of "ten minutes nobody needs you" *is* midlife mental load. |
| **Defensible by stack** | Common phrase is hard to trademark naked, but as a brand-stack ("The Quiet Hour™ Mask") it protects and competitors look silly copying. |
| **Domain + handle availability** | Searches found no beauty/wellness conflicts. WHOIS verification pending. |
| **Aesop-tier elegance** | Sounds like a poem, looks good on packaging. |

## 7. Identity primitives

### Wordmark
- Format: lowercase wordmark — `the quiet hour`
- Type: light serif. Working pick: Reckless Neue Light Italic (or Garamond Premier Pro Italic as fallback)
- Trademark mark: superscript ™ on first occurrence per page
- Monogram: `tqh` lockup for favicon and IG profile pic

### Colour palette (already in `theme/assets/base.css`)
```
--color-bg: #faf7f4    /* warm cream */
--color-bg-alt: #f1ece5 /* warm beige */
--color-text: #2a201c   /* deep brown-black */
--color-text-muted: #7a6b62
--color-accent: #8b4a3a /* muted terracotta — CTA */
--color-discount: #a44d3c
--color-trust: #c89b4e  /* warm gold for stars */
```

### Photography direction
- Real women aged 40–55, no obvious retouching
- Settings: domestic interiors. Bathroom, bedroom, reading chair, kitchen window
- Props: linen robe, ceramic mug, candle, book face-down, eye-mask (not the LED one)
- Lighting: window light, golden-hour, single warm-key light at night
- Shot list: woman applying mask, woman wearing mask reading, mask on bedside table, hands holding box, woman drying face on towel post-treatment

### Tone of voice
- Default to lowercase
- One idea per sentence
- Em-dashes used freely — like this
- Periods soft. Commas patient.
- Specificity over hype: "ten minutes" not "a moment"; "47" not "40-something"
- Never uses: anti-ageing, miracle, instant, fight, defy, combat, mature, crepey

## 11. Risks + mitigations

| Risk | Mitigation |
|---|---|
| Common phrase usage in published works (novels, songs) | Phrase trademarks live inside a *category*. Beauty/wellness is the category — clear so far. File AU + US trademark in Class 3 (cosmetics) + 10 (medical/wellness devices) + 35 (retail). |
| Three-word URL longer to type | Most discovery is via paid ads / IG bio links / direct navigation — typing isn't the entry point |
| Could read feminine-coded; limits future male SKUs | Brand thesis (solitude) is gender-neutral; visual flex is possible. Not a blocker for the current 38–55 women target. |
| Phrase becomes generic if competitors imitate | Always pair with brand mark or possessive ("your Quiet Hour", "The Quiet Hour™") to keep it brand-tagged, not generic |
